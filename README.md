# Escuela Asedem

Demo independiente de Mi ASEDEM y Escuela Asedem. Sirve esta carpeta como sitio estático (por ejemplo, con `python3 -m http.server`). En Vercel, usa el preset Other y la raíz del repositorio. No requiere instalación ni compilación.

El directorio, las iniciativas, la revisión y la inscripción usan datos ficticios y almacenamiento local del navegador. El logo procede de la web de ASEDEM.
